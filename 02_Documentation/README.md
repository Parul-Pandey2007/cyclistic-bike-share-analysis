# Project Documentation

## 1. Original Source Data

The project uses 12 original monthly CSV files containing historical bike-trip records from April 2021 to March 2022.

- **Data Provider:** Motivate International Inc.
- **Dataset:** Divvy historical bike-trip data.
- **Time Period:** April 2021 – March 2022.
- **File Format:** CSV.

These original files served as the primary source data for the analysis. They are retained locally and are not included in this GitHub repository.

## 2. Working Files

The original datasets were used as the basis for the analysis. The data was worked on separately using WPS Spreadsheet, and the resulting working files were saved and organized locally.

The consolidated full-year workbook included in this repository contains the supporting analysis tables, calculations, summary metrics, and annual dashboard.

## 3. Analysis Process

The analysis involved:
- Calculating ride durations.
- Identifying the day of the week for each ride.
- Checking data quality issues.
- Comparing casual riders and annual members.
- Examining monthly riding trends and average ride durations.
- Identifying key findings and patterns.

## 4. Final Project Deliverables

The repository includes:
- Consolidated full-year analysis workbook.
- Annual dashboard image.
- Final Cyclistic case study report.

## 5. Tools Used

- **WPS Spreadsheet:** Data preparation, calculations, analysis, and dashboard creation.
- **WPS Writer:** Final project report.
- **GitHub:** Project documentation and portfolio presentation.
